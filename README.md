# War and Peace — Interactive Paginated Mobile Edition

An interactive, paginated web edition of Leo Tolstoy's **War and Peace**, divided into Books, Chapters, and Pages matching the original PDF reference.

## 📖 Live Web Reader
👉 **Read online:** [https://docapt-max.github.io/war-and-peace/](https://docapt-max.github.io/war-and-peace/)

## ✨ Key Features
- **Structured Hierarchy**: Divided cleanly into **17 Books**, **365 Chapters**, and **2,019 Pages** (referencing original PDF pages 25–2043) instead of an endless wall of text.
- **Two Reading Modes**:
  - **Page View (Default)**: Single-page focused e-reader mode with tap/swipe page turns, progress bar, and page numbers.
  - **Chapter View**: Displays the active chapter divided into styled page sheets with running headers and page dividers.
- **Accessible Book Index**: Tap `[☰ Index]` anytime to browse all 17 books and 365 chapters with page ranges, or enter any page number (25–2043) for instant jump.
- **Family Tree Character Highlighting**: Over 9,100 character mentions color-coded by aristocratic house (Bezukhov, Bolkonsky, Rostov, Kuragin, Drubetsky, Karagin, Others).
- **Interactive Tooltips**: Tap any highlighted name to see character biographical details, relationships, and context from the reference family tree.
- **Dark Theme by Default**: Gentle on the eyes for extended reading sessions on phone or tablet.
- **Collapsible Cover Art**: High-resolution cover viewer featuring Mikhail Klodt's *Volga Near Simbirsk* (1881).
- **Mobile Touch Controls**: Swipe left/right to turn pages, sticky bottom navigation toolbar, font scaling `[A−]` and `[A+]`.
- **Automatic Progress Saving**: Automatically remembers your exact page and reading mode in local storage.
