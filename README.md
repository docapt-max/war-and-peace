# War and Peace — Interactive Mobile Edition

An interactive, continuous-flow web reader of Leo Tolstoy's **War and Peace**, optimized for mobile reading.

## 📖 Live Web Reader
👉 **Read online:** [https://docapt-max.github.io/war-and-peace/](https://docapt-max.github.io/war-and-peace/)

## ✨ Key Features
- **Seamless Flow**: Continuous text flow with zero artificial page breaks, running headers, or footers.
- **Family Tree Character Highlighting**: Over 8,500 character mentions color-coded by aristocratic house (Bezukhov, Bolkonsky, Rostov, Kuragin, Drubetsky, Karagin).
- **Interactive Tooltips**: Tap any highlighted name to see character biographical details, relationships, and context from the reference family tree.
- **Dark Theme by Default**: Easy on the eyes for extended reading sessions on phone or tablet.
- **Collapsible Cover Art**: High-resolution cover viewer featuring Mikhail Klodt's *Volga Near Simbirsk* (1881).
- **Mobile Optimized**: Responsive typography, touch-friendly navigation, quick chapter jump bar, reading progress indicator, and persistent chapter drawer.
